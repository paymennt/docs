# Build with Paymennt

Use Paymennt to accept payments with a hosted flow, payment links, ecommerce plugins, or a custom API integration.

## Choose your integration path

- **Start accepting payments quickly** — [Payment links](/docs/payment/links/)
- **Add payments to an ecommerce store** — [Ecommerce plugins](/docs/payment/ecomm/)
- **Build a custom web checkout** — [Web payment frames](/docs/payment/frames/)
- **Build a mobile payment flow** — [Mobile payments](/docs/payment/mobile/)
- **Receive payment updates** — [Webhooks](/docs/track/webhooks/)

## A practical integration lifecycle

1. **Build** — choose an integration approach and create your payment flow.
2. **Test** — verify payment handling, error states, and webhook delivery.
3. **Go live** — complete the [website checklist](/docs/golive/checklist/).
4. **Operate** — manage subscriptions, account details, and payment events.
